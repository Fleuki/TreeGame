# Лесорубы

Браузерная игра-дуэль на одном экране: двое рубят свои деревья наперегонки.
Одностраничное приложение — всё в одном файле `index.html`. Без сборки,
без внешних библиотек, CDN и шрифтов. HTML + Canvas + чистый JS.

## Как играть

Экран делится пополам, у каждой зоны своё дерево и свой счётчик. Раскладка
подбирается под экран:

- **телефон** (экран выше, чем шире) — зоны друг над другом, верхняя
  развёрнута на 180°. Игроки садятся с двух сторон телефона: один снизу,
  второй сверху, и каждому достаётся вся ширина экрана под тап;
- **ПК и альбомная ориентация** — зоны слева и справа.

- Тапни по **левой** или **правой** половине своей зоны — лесоруб перейдёт на
  эту сторону ствола и ударит.
- Каждый чистый удар: нижний сегмент отлетает, ствол опускается, сверху
  добавляется новый. **+1 очко**.
- Если на нижнем сегменте была ветка с той стороны, куда ты ударил, —
  **ошеломление на 0.7 секунды**: тапы игнорируются, очки не идут, зона
  краснеет и трясётся.
- Первый, кто набрал **50 очков**, побеждает.

На десктопе то же самое с клавиатуры: `A` / `D` — левый игрок,
`←` / `→` — правый.

## Режимы

- **Против бота** — три уровня: «Легко», «Нормально», «Сложно». Бот рубит с
  интервалом, который сокращается по мере набора очков, и иногда сам бьёт по
  ветке. На экране выбора только названия; цифры ниже — для правки в коде
  (константа `DIFFICULTY`):

  | Уровень    | Интервал удара | Шанс ошибки |
  |------------|----------------|-------------|
  | Легко      | 780 → 420 мс   | 20 %        |
  | Нормально  | 550 → 260 мс   | 12 %        |
  | Сложно     | 420 → 190 мс   | 6 %         |

- **На двоих** — два игрока на одном экране, каждый в своей половине.
  Мультитач: удары обрабатываются независимо.

## Генерация дерева

Новые сегменты случайны, но по правилам:

- вероятность ветки — 35 %;
- не больше двух веток подряд с одной стороны;
- первые три сегмента при старте — всегда без веток.

## Запуск

Достаточно открыть `index.html` в браузере. Локально удобнее через любой
статический сервер, например:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Публикация

Игра выкладывается на **GitHub Pages** через GitHub Actions: workflow
`.github/workflows/pages.yml` на каждый пуш в `main` публикует корень
репозитория как есть. Сборки нет, настраивать источник в Settings не нужно —
workflow включает Pages сам (`configure-pages` с `enablement: true`).

Перевыложить вручную: вкладка Actions → *Deploy to GitHub Pages* → Run workflow.

## Устройство файла

Скрипт разбит на секции с комментариями:

| Секция | Что внутри |
|--------|------------|
| Палитра | объект `PALETTE` — все цвета игры |
| Константы | очки до победы, тайминги, вероятности, сложности бота |
| Состояние | сцена, игроки, их стволы, таймеры и частицы |
| Звук | Web Audio API, тона генерируются на лету, без файлов |
| Генерация дерева | `nextSegment`, `buildTrunk`, `ensureTrunk` |
| Разметка | масштаб под `devicePixelRatio`, выбор раскладки зон, `withZone` |
| Ввод | `touchstart` (без задержки `click`), мышь и клавиатура |
| Логика | удар, ошеломление, частицы, тряска, отсчёт |
| Бот | темп и ошибки |
| Отрисовка | фон, ствол, ветки, лесоруб, HUD, меню |
| Цикл | `requestAnimationFrame` + фиксированный шаг логики (1/120 с) |

## Про графику

Сейчас всё нарисовано примитивами — прямоугольники и круги. Задача этапа —
ощущение игры, а не арт. Поэтому:

- все цвета вынесены в `PALETTE` вверху файла;
- отрисовка разделена на `drawTrunkSegment`, `drawBranch`, `drawLumberjack`,
  `drawGround` — их можно заменить на спрайты, не трогая логику.

## Ощущение

- тряска зоны на удар (~3.5 px) и сильная на ошеломление;
- белая вспышка на удар, красная — на ошибку;
- щепки и листья частицами;
- звук каждого удара через Web Audio API;
- замах и удар лесоруба за 0.1 с;
- ствол опускается твином за 0.08 с;
- счётчик с pop-анимацией и полоской прогресса до 50;
- реакция на `touchstart`, без задержки;
- выключены выделение текста, зум по двойному тапу и контекстное меню;
- вертикальная ориентация приоритетна, но верстка работает и в альбомной.
